- Learn JSON response generation.

    ↓
Frontend
    ↓
Backend
    ↓
AI Model
    ↓

    ↓
Frontend Autofill

## Research Notes

### What is Prompt Engineering?
Prompt engineering is the process of writing clear and specific instructions for an AI model to generate accurate and useful responses.

### What is JSON?
JSON (JavaScript Object Notation) is a lightweight format used to exchange structured data between applications.

Example:

```json
{
  "name": "Bhavana",
  "email": "bhavana@example.com"
}
```
